# Scissor landing page (Figma to HTML/CSS)

Static HTML and CSS conversion of the **AltSchoolV2 Exam** Figma design: a URL-shortener landing page with hero, stats, features, pricing, shorten form, FAQs, closing call to action and footer.

- Plain HTML, CSS and a little vanilla JS (mobile menu and FAQ accordion). No build step.
- Designed at 1440px wide and fluid/responsive below that (tablet and mobile layouts).
- Colours, spacing, type sizes and copy follow the Figma file. Font is Outfit (Google Fonts) as a stand-in for Gilroy.
- Logo, hero artwork, FAQ/footer/closing backgrounds and footer brand are SVGs exported from Figma (in `assets/`). Small UI icons are inline SVG.

## How to view it

https://lionabiola-bit.github.io/ALTSCHOOL-figma-to-HTML-and-CSS/

## Structure

```
index.html
css/style.css
js/main.js
assets/   (SVGs exported from Figma)
```

## Run locally

Open `index.html` in a browser.
